## 评分规则

- 两项比赛**均不进行轨迹（trace）评分**，最终排名**完全按照任务本体分数**。
- 评分规则完全以题面为准，不需要额外揣测。
- 因为不看轨迹，**可以自由组合 Multi-Agent、Sub-Agent 等任意 Agent 架构方案**。

## 轨迹上传（trace 大小上限）

- 主站存在一个 **500KB 的大小上限**，但这只是主站 Werkzeug 的配置项，**不影响比赛进行**，也不必等平台改配置或新版 CLI。
- 原理：Werkzeug 只限制**非文件字段**；带 `filename` 的部分（multipart 文件字段）直接写磁盘，不受 500KB 限制。
- **立即可用的绕法**：把 trace 改成**以文件形式上传**（CLI/脚本把 trace 当文件传）。服务端 400 错误提示里说明的也是这条路。
- 实测 7.49 MB 的 trace 现在就能提交成功。

## 重要红线

- **不得向比赛算力池中提交非比赛任务**，平台管理员会监控任务内容。

## 参赛要点（摘自参赛指南）

1. 赛前准备：完成《Bohr-CLI使用指引》和《加入比赛GPU算力池》两篇文档的步骤
2. 在比赛平台 https://play.bohrium.com/ 注册账号并登录
3. 右上角头像 → 左侧「API接入」→「生成令牌」，创建专用 Agent Token
4. **Token 只完整显示一次**：保存到密码管理器或安全的环境变量，不要发群聊、截图或提交到代码仓库
